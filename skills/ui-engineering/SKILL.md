# UI Engineering — Hub de Construção de Interfaces

Bundle especializado em direção de arte, sistemas de design tátil, acessibilidade e interfaces profissionais.

## Sub-skills

| Sub-skill | Quando usar |
|---|---|
| [`frontend-design`](frontend-design/SKILL.md) | Direção visual, tipografia refinada e layout moderno. |
| [`accessibility`](accessibility/SKILL.md) | Requisitos de acessibilidade (WCAG 2.2, ARIA, foco e navegação por teclado). |
| [`tactile-hyperreal-ui-auditor`](tactile-hyperreal-ui-auditor/SKILL.md) | Auditoria e acabamento tátil de alta fidelidade (iluminação 315°, sombras multicamadas, 4K Feel). |
| [`color-palette-and-depth-architect`](color-palette-and-depth-architect/SKILL.md) | Paletas de cores acessíveis, contraste AA/AAA e profundidade de elevação. |
| [`minimal-ui-menu-icon-architect`](minimal-ui-menu-icon-architect/SKILL.md) | Menus minimalistas (dock, sidebars, navbars) e ícones vetoriais em SVG sem emojis. |
| [`responsive-html-ui-master`](responsive-html-ui-master/SKILL.md) | Layouts responsivos HTML5/CSS3 com abordagem mobile-first e submenus fluidos. |
| [`design-interface-medica-minimalista`](design-interface-medica-minimalista/SKILL.md) | Interfaces médicas, receituários e calculadoras com impressão A4 e conformidade CFM. |

## Zonas de Não-Ação & O que NÃO Fazer
- NUNCA usar emojis em interfaces corporativas ou médicas de alta sobriedade.
- NUNCA criar layouts que quebrem a acessibilidade de contraste ou navegação por teclado.
