# Perfil: Ferramenta de design / editor / IDE web

Canvas, editores de fluxo/código/imagem, IDEs, whiteboards. Interação contínua, atalhos, múltiplos painéis.

## Ajustes de peso
- D1: 40% (interação é o núcleo)
- D2: 25%
- D3: 10%
- D4: 25%

## Itens adicionais (só neste perfil, +20 pts distribuídos em D1)
- **D1.9 Canvas/pan/zoom (8 pts)**: pan por arraste ou espaço, zoom com ctrl+scroll, conteúdo permanece navegável em qualquer zoom
- **D1.10 Atalhos de teclado (6 pts)**: paleta de comandos (⌘K/Ctrl+K), atalhos documentados ou descobríveis, Esc consistente
- **D1.11 Painéis (6 pts)**: redimensionáveis ou recolhíveis; estado persiste ao alternar abas/views

## Regras específicas do perfil
- Roteiro behavioral obrigatório: clicar em ≥15 controles, abrir paleta de comandos, arrastar um elemento do canvas
- Abas e navegação multi-view contam como D1.3 (cada aba é uma "rota")
- D2.5 adaptado: painéis sobre painéis (>2 níveis de aninhamento visual) penalizam; densidade alta é esperada — o critério é **organização**, não quantidade
- Contraste em canvas com fundo pontilhado/gradeado: medir o texto contra o pior caso do fundo
- Tema claro/escuro é esperado; se declarado, auditar os dois (ver D4.8 na rubrica)
