# Perfil: Landing Page / Marketing

Páginas públicas de conversão: hero, seções, CTA, footer. Sem autenticação, sem dados dinâmicos densos.

## Ajustes de peso
- D1: 25% (menos interação, menos que pode quebrar)
- D2: 35% (design é o produto)
- D3: 20% (copy e tipografia carregam a conversão)
- D4: 20%

## Itens marcados N/A por padrão
- D1.5 (formulários) — N/A exceto se houver form de contato/newsletter; aí avaliar só ele
- D1.6 (estados) — manter só se há conteúdo dinâmico (fetch, carrinho)
- D4.5 (forms acessíveis) — segue D1.5

## Regras específicas do perfil
- CTA primário deve ser identificável em <2s olhando a dobra inicial — falhar aqui zera metade de D2.1
- Hero com proposta de valor legível sem scroll (D3.2 em dobro)
- Velocidade pesa mais: LCP > 2.5s → D1.1 cai para metade mesmo renderizando
- Densidade baixa **não** é defeito; espaço em branco generoso é virtude (inverter a lógica de D2.5)
