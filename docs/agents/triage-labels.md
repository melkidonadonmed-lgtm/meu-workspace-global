# Triage Labels

## Canonical mapping

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

## Consumer guidance

Use exatamente esses labels ao classificar issues. Não crie aliases ou variações sem atualizar este arquivo.
